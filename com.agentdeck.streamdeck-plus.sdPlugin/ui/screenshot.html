Screenshot to AI

Privacy

The capture happens on the press and nowhere else. AgentDeck writes it to a temporary file, hands the path to the agent, and deletes it as soon as the send finishes — whether or not the send worked. No copy is kept, and the image never reaches a log file.

The image goes to the provider you pick, so it leaves this machine exactly as far as that provider takes it. Capture the active window rather than all screens when other windows are open.

Windows only.
