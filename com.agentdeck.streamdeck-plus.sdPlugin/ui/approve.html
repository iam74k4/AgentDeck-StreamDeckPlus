Approve Once

Seconds a high-risk request must be held before it is approved. Low- and medium-risk requests are approved on a single press. Clamped to 0.5–5 seconds.

This key only ever approves the one request on screen. There is no "always approve": the next request is asked again.

Only Codex can raise approvals. Claude Code is monitored through its status line and has no approval channel.
