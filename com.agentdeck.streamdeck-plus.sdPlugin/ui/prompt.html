Prompt

A preset says where its input comes from — the clipboard, the current selection, or a screenshot — and where the result goes. Leave this empty to run whichever preset the Prompt dial has selected.

Fill this in to send the same thing every press. It replaces the preset's input source, so the clipboard is not read.

Claude Code has no control channel, so prompts can only be sent to Codex. Clipboard, selection and screenshot capture need Windows.
